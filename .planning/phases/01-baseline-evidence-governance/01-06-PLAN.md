<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Previous revision -> current head | History can be truncated, reordered, rewritten, or hash-spoofed. |
| Live repo/source/target -> frozen identity | Drift can remain falsely current if only one fingerprint is compared. |
| Paths/text/aliases -> validator diagnostics | Malicious values can escape roots, exhaust parsing, inject markup, or leak secrets. |
| Negative corpus -> production behavior | Verification data can become an alternate implementation source if read before production completion. |

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-01 | Tampering/Repudiation | ancestry | high | mitigate | Separate removal/reorder/rewrite/hash cases and mandatory full traversal. |
| T-06-02 | Spoofing/Tampering | drift fingerprints | high | mitigate | Independent HEAD/tree/license/content/source/target cases and typed stale output. |
| T-06-03 | Elevation/Disclosure | filesystem and diagnostics | high | mitigate | Bounded reads, root containment, synthetic symlink/oversize inputs, and redaction verification. |
| T-06-04 | Tampering | implementation boundary | high | mitigate | Plan 01-04 prerequisite, post-implementation generation, and no fixture-path/case-ID production branch. |
</threat_model>
