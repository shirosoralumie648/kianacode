<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Evidence revision -> current projection | A rewritten, reordered, or truncated predecessor can falsify current proof. |
| Legacy files -> classification ledger | A new or edited status-bearing document can silently regain authority. |
| Bundle selector -> canonical loaders | A selector could spoof the chosen head or duplicate completion state. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-02 | Spoofing/Tampering | canonical selector | high | mitigate | Path/hash-only closed bindings; semantic validator rehashes every head. |
| T-02-03 | Tampering | legacy authority | high | mitigate | Exact inventory, per-path hash/rationale/replacement, and revisioned review. |
| T-02-SC | Tampering | dependency supply chain | low | accept | No package-manager action or dependency file is in scope. |
</threat_model>
