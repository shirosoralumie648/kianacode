<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Official/public material -> controlled artifact | Rolling/conflicting pages can be spoofed, disappear, or contain unsafe text. |
| Artifact entries -> public capabilities | Omission, duplicate mapping, or exclusion can hide required public behavior. |
| Local observations -> proof state | Local/source evidence can be mislabeled target or user proof. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-01 | Spoofing/Tampering | official artifact | high | mitigate | Official/archive URI, retrieval/product metadata, normalized whole/entry hashes, offline rehash. |
| T-08-02 | Tampering/Repudiation | source index | high | mitigate | Exhaustive one-to-one map/exclusion oracle and reviewed successor ancestry. |
| T-08-03 | Spoofing | proof assignment | high | mitigate | Separate axes, matching evidence, source/local cap, conflicts blocked. |
| T-08-04 | Information Disclosure | source artifact | medium | mitigate | Public material only; reject credentials/private bytes/absolute paths. |
</threat_model>
