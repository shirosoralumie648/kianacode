<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Schema-valid objects -> semantic graph | Closed JSON shape can still hide missing coverage, dangling identities, stale proof, or rewritten history. |
| Revision/head bindings -> filesystem | Caller paths and hashes can escape roots or select an unbound predecessor. |
| Live repository/source/target -> frozen identity | Partial fingerprint comparison can leave changed evidence falsely current. |
| Untrusted values -> diagnostics | Paths, markup, size, and secret-shaped values can escape or leak through output. |

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-01 | Tampering/Spoofing | coverage and identities | high | mitigate | Bidirectional source mapping, unique IDs, exact aliases, and one current decision per capability. |
| T-04-02 | Tampering/Repudiation | ancestry and evidence | high | mitigate | Mandatory full traversal, immutable prefix hashing, highest-sequence evidence, explicit evaluation time. |
| T-04-03 | Spoofing/Tampering | drift fingerprints | high | mitigate | Independent HEAD/tree/license/content/source/target comparison and typed stale proposals. |
| T-04-04 | Elevation/Disclosure | loaders and diagnostics | high | mitigate | Bounded reads, root containment, deterministic redaction, and exact error statuses. |
</threat_model>
