<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Caller/environment -> Rust supervisor | Caller-controlled paths, modes, or environment can forge authority unless ignored or validated. |
| Rust supervisor -> fixed Linux launchers | Replaced or writable launchers can bypass sandbox, trace, or worker protocol. |
| Supervisor -> Rust worker-launcher -> hidden Bash worker | Rust consumes the launch token, withholds authority FDs from Bash, and binds Bash exit `80` to one post-exit receipt. |
| Child output/trace -> final verdict | Malformed, truncated, unknown, or oversized observations must never become success. |
| Cleanup -> publication | `offline=true` must not publish until all process and runtime-root cleanup is proven. |

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-01 | Spoofing/Elevation | launcher and Python binding | high | mitigate | Canonical root-owned paths, permission checks, fixed canary, and no caller path selection. |
| T-03-02 | Tampering/Spoofing | hidden worker protocol | high | mitigate | Rust-owned inherited FDs, post-exit token-correlated receipt, Bash exit `80`, exact parser, and Rust-only verdict. |
| T-03-03 | Denial/Tampering | deadline and drains | high | mitigate | One monotonic deadline, bounded concurrent drains, signal escalation, and typed timeout states. |
| T-03-04 | Repudiation/Disclosure | trace, output, and receipt | high | mitigate | Bounded parsers, exact positive conjunction, redaction, and no raw trace publication. |
| T-03-05 | Elevation/Repudiation | cleanup and archive | high | mitigate | Process-group cleanup, runtime-root removal, leak probes, protected hashes, and two fresh archive gates. |
</threat_model>
