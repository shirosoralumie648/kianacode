<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Local evidence -> product projection | Low-level tests and narratives can be mislabeled verified target/user proof. |
| Dirty legacy files -> authority classification | Editing/staging them can absorb user work or leave duplicate completion state. |
| Current selector -> canonical heads | Wrong path/hash can select rewritten or foreign family data. |
| Legacy inventory -> focused runner | Missing or newly added status-bearing paths can evade canonical retirement. |

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-10-01 | Spoofing/Tampering | evidence proof | high | mitigate | Subject/source/target/environment binding, level caps, immutable prefix and record hashes. |
| T-10-02 | Tampering/Repudiation | legacy authority | high | mitigate | Full exact inventory, content hashes, rationale/replacement, no legacy writes. |
| T-10-03 | Tampering | current selector | high | mitigate | Closed path/hash-only manifest and full semantic rehash/traversal. |
| T-10-04 | Spoofing | legacy gate | medium | mitigate | Live path-set equality plus per-path hash and classification validation. |
| T-10-SC | Tampering | dependency supply chain | low | accept | Standard library and existing runner only; no install or dependency change. |
</threat_model>
