## Trust Boundaries

| Boundary | Description |
|---|---|
| Policy-approved artifact -> freeze CLI | Artifact provenance/hash may be missing or spoofed. |
| Live fingerprints -> drift report | Partial or unavailable observations can be mislabeled current. |
| Drift report -> successor revisions | Crafted affected IDs can rewrite unrelated state or omit stale events. |

| T-07-03 | Elevation | output roots | high | mitigate | Explicit contained roots, temp staging, atomic rename, no overwrite. |
