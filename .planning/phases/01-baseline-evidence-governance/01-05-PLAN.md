## Trust Boundaries

| Boundary | Description |
|---|---|
| Previous revision -> current head | History can be truncated, reordered, rewritten, or hash-spoofed. |
| Live repo/source/target -> frozen identity | Drift can remain falsely current if only one fingerprint is compared. |
| Paths/text/aliases -> validator diagnostics | Malicious values can escape roots, exhaust parsing, inject markup, or leak secrets. |

| T-05-02 | Spoofing/Tampering | drift fingerprints | high | mitigate | Independent HEAD/tree/license/source/target cases and stale event expectations. |
| T-05-03 | Elevation/Disclosure | filesystem and diagnostics | high | mitigate | Bounded reads, root containment, synthetic symlink/oversize, redaction tests. |
| T-05-04 | Tampering | aliases/domains | medium | mitigate | Exact closed shape and alternate-name negative cases. |
