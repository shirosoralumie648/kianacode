# Kiana Reference Feature Matrix

Date: 2026-06-24

This matrix tracks migration progress from `reference/` projects into Kiana. A row is only `complete` when the listed tests and evidence cover the behavior, not merely because a similarly named command or module exists.

## Recent Commercial Hardening

- Skills/plugins/project automation: `stream-json` init events now report visible user/project/plugin skills and installed plugin summaries instead of empty placeholders. Disabled plugins remain visible in plugin status summaries, while their skills and slash commands disappear from active init surfaces. Covered by `cargo test -p kiana-entrypoints stream_json_init_reports --locked`, `cargo test -p kiana-commands plugin --locked`, and `cargo test -p kiana-commands skills_command_hides_disabled_plugin_skills_from_active_surfaces --locked`.
- Plugin marketplace policy: local/ cached marketplace manifests now surface plugin `interface` and `policy` metadata in `marketplace list --json`, reject `not_available` plugins during install, hide disabled plugin agents through the shared enabled-plugin root resolver, enforce managed plugin allow/deny policy, and write pinned install receipts with stable content hashes. Covered by `cargo test -p kiana-commands plugin --locked`, `cargo test -p kiana-entrypoints agents_discovery_lists_sources_and_marks_shadowed_agents --locked`, and `bash scripts/release-smoke.sh`.
- Knowledge indexing: `kiana context index/search/pack` now provides a deterministic local file index, ranked lexical/path-aware search, root-scoped local artifact packs, and snippet-pack foundation for future RAG flows, with pinned JSON schemas and release/package smoke gates. Covered by `cargo test -p kiana-query context_index --locked`, `cargo test -p kiana-query context_search --locked`, `cargo test -p kiana-query context_pack --locked`, `cargo test -p kiana-commands context_index --locked`, `cargo test -p kiana-commands context_search --locked`, `cargo test -p kiana-commands context_pack --locked`, and `bash scripts/release-smoke.sh`.
- Product shell/app-server: direct-connect now exposes a bearer-protected `/app` contract with conversations, bounded session event snapshots, settings/readiness sections, redacted secrets, sandbox, plugin status, and git-status endpoints. `/app/plugins` reports enabled/disabled plugin summaries plus component counts, including app manifests. Covered by `cargo test -p kiana-entrypoints direct_connect_app_contract --locked`.
- Provider adapter contract: the fake provider now has a standard adapter test pack covering metadata, text, unsupported tools, tool calls, synthetic streaming, and provider error codes. Covered by `cargo test -p kiana-services --test provider_standard --locked`.
- Reference diagnostics: `kiana doctor --json` now emits `reference_capabilities`, a release-smoke-validated matrix that maps the major reference-parity domains to local evidence and remaining risks instead of leaving capability status only in docs. Covered by `cargo test -p kiana-commands doctor_json_reports_reference_capability_matrix --locked`, `bash scripts/schema-contract-smoke.sh`, and `bash scripts/release-smoke.sh`.
