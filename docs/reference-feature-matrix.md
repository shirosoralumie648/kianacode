# Kiana Reference Feature Matrix

Date: 2026-07-05

This matrix tracks migration progress from `reference/` projects into Kiana. A row is only `complete` when the listed tests and evidence cover the behavior, not merely because a similarly named command or module exists.

## Recent Commercial Hardening

- Runtime tool-result file changes: `Write`, `Edit`, and `Delete` tool results now emit stable `changed_files` metadata, and local runner, RuntimeEvent, stream-json, remote SDK adapter, bridge adapter, app-server event schema, and SDK docs preserve the same file-change list for product file-change panels. `Delete` follows the same conservative mutation guard as edits by requiring prior read state, an unchanged mtime, and editable/read-only permission checks before removal. `kiana diff --session-changes <session-id> --json` now reads session `events.jsonl` and emits a stable `kiana.diff.session_changes.v1` aggregate with sorted files, operations, sources, and empty legacy-session reports for events without metadata; TUI `/diff` command replay renders the same schema as a file changes preview instead of raw JSON, and bridge consumers can generate the same aggregate from runtime events via `bridge_session_changes_report()`. Bridge consumers can also project the same runtime event sequence into the pinned `kiana.app-server.events-view.v1` transcript shape through `bridge_events_view_report()`, preserving changed-file metadata on tool-result messages. `kiana checkpoint restore <checkpoint-dir-or-manifest> --json` now emits `kiana.checkpoint.restore.v1` with per-file restore `changed_files` before/after existence metadata for patch and untracked restores. Covered by `cargo test -p kiana-tools write_api_result_reports_changed_file_metadata --locked`, `cargo test -p kiana-tools edit_api_result_reports_changed_file_metadata --locked`, `cargo test -p kiana-tools delete_api_result_reports_changed_file_metadata --locked`, `cargo test -p kiana-tools delete_requires_file_to_be_read_first --locked`, `cargo test -p kiana-tools delete_rejects_files_not_listed_as_editable --locked`, `cargo test -p kiana-commands diff_session_changes_json --locked`, `cargo test -p kiana-entrypoints tui_session_changes_diff_json_result_renders_file_changes_preview --locked`, `cargo test -p kiana-bridge bridge_session_changes_report_aggregates_runtime_changed_files --locked`, `cargo test -p kiana-bridge bridge_events_view_report_projects_runtime_events_for_clients --locked`, `cargo test -p kiana-commands checkpoint_restore_json_reports_before_after_file_changes --locked`, `cargo test -p kiana-entrypoints runner_runtime_event_adapter_preserves_changed_files --locked`, `cargo test -p kiana-entrypoints stream_json_partial_event_exposes_tool_result_changed_files --locked`, `cargo test -p kiana-remote remote_sdk_adapter_emits_runtime_events_for_messages_tools_and_results --locked`, `cargo test -p kiana-bridge bridge_sdk_adapter_preserves_tool_result_changed_files --locked`, `cargo test -p kiana-types runtime_event_schema_covers_required_payloads --locked`, and `bash scripts/schema-contract-smoke.sh`.

Covered by `cargo test -p kiana-entrypoints maps_result_event_without_assistant_text_to_terminal_status_message --locked`.
- Hook source visibility matrix: `PreToolUse` hooks now have direct source-matrix coverage proving home hooks stay available, trusted project hooks load, untrusted project hooks are ignored, enabled plugin hooks load, and disabled plugin hooks do not run; `SessionStart`, `UserPromptSubmit`, and `PostToolUse` now have focused project-trust boundary fixtures proving untrusted project hooks are ignored while home hooks remain active. Covered by `cargo test -p kiana-query pre_tool_use_hooks_respect_home_project_plugin_and_trust_sources --locked` and `cargo test -p kiana-query --locked project_trust_source_boundary`.

Local slash commands stay out of the model path, prompt commands expand before model execution, and unknown slash commands return a local error. Covered by `cargo test -p kiana-entrypoints repl --locked` and `cargo test -p kiana-entrypoints --lib tui::tests:: --locked`.
