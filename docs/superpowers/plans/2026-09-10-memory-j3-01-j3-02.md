**Goal:** 落地记忆架构 spec 的第一切片：`MemoryRecord v2`（origin / admission_state / classification）+ 模型写入 candidate 准入 + 检索打分归一（CLI/harness 同一实现）+ 命中进收据。

**Tech Stack:** Rust（stable，workspace）；serde serde_json；无新外部依赖。

**Spec:** `docs/superpowers/specs/2026-09-10-memory-architecture-design.md`（§4 数据模型、§7 三档准入、§6 检索、§8 收据）

## Global Constraints

- **不新增模型可见工具**（保持 5 个）；`memory.search`/`memory.write` 的 schema 与映射不变。
- **redaction 不放松**：所有新事件/输出继续过既有 redact 边界。
- **JSONL append-only**：任何状态变化都是追加新行，不物理改写旧行。
- **serde 默认值兼容 v1**：v1 行必须能原样解析（`#[serde(default)]`），不迁移文件。
- **`kiana-types` 不得引入新外部依赖**（纯类型 + 纯函数）。
- 所有 cargo 命令带 `--locked --offline`（仓库 gate 惯例）。
- **代码提交需用户显式授权**（当前只有 roadmap 提交授权；实现提交每步先问或按固定节奏派 Codex）。

```rust
//! 共享记忆记录类型与检索打分（spec §4/§6）。v1 行靠 serde default 兼容。
use serde::{Deserialize, Serialize};
use serde_json::Value;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum MemoryOrigin { Model, Hook, Git, User }

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum AdmissionState { Candidate, Qualified, Ephemeral }

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Classification { Public, Company, Department, Role, Project, Packet, UserPrivate, Scratch }

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct MemoryRecord {
    pub schema: String,
    pub id: String,
    pub layer: String,
    pub collection: String,
    pub text: String,
    pub source: String,
    pub role_id: String,
    pub department_id: String,
    pub session_id: String,
    pub created_at_ms: u64,
    // v2 字段：v1 行缺省时按此处 default 落地
    #[serde(default)]
    pub origin: MemoryOrigin,                       // 注意：v1 兼容见下方说明
    #[serde(default = "default_qualified")]
    pub admission_state: AdmissionState,
    #[serde(default)]
    pub classification: Classification,
}

fn default_qualified() -> AdmissionState { AdmissionState::Qualified }
```

**`origin` 的 v1 语义修正（对 spec §4 的落地细化）**：serde `#[serde(default)]` 无法表达「缺省 = 不可指认」，所以 v1 兼容解析走两步——先用 `serde_json::Value` 检查 `origin` 键是否存在：缺失时 `origin` 记为 `MemoryOrigin::User` 但**同时** `admission_state` 保持 `Qualified` 且 `hit` 输出里 `provenance: "unverifiable"`（对应 spec「origin/evidence 缺失即 provenance 不可指认，Reviewer 不得引用」）。实现为 `MemoryRecord::from_value(v: &Value) -> Result<MemoryRecord, _>` 入口函数（内部先探测键，再 serde 反序列化），**不要**只靠 derive default。

`match_terms(text, terms) -> Vec<String>`：词项小写化、返回 text 中命中的词项列表；`score_match(text, terms) -> u64` = `match_terms(..).len() as u64`（语义与 `kiana-commands/src/memory.rs:354` 现有一致）。两个函数都要，检索方先拿 matched_terms 展示、再拿 score 排序。

- [ ] **Step 3: 实现**

1. `MemoryWriteHandler::execute`：broker 路径恒 `MemoryOrigin::Model`（服务端事实，不读 arguments）；调用 `write_record(&arguments, MemoryOrigin::Model)`。
2. `write_record`：按 spec §7 三档——`origin=Model && layer != instance` → `AdmissionState::Candidate`；`layer == instance` → `Ephemeral`；`origin=User` → `Qualified`。`classification` 由 `layer`/collection 映射表派生（company→Company、user/user-private→UserPrivate、department:X→Department、role:X→Role、project*:→Project、instance→Scratch）。schema 写 `MEMORY_RECORD_SCHEMA_V2`。
3. `read_records`：解析全部行后按 `id` 保留**最后一行**（append-only 末行生效），测试锁死该语义。
4. `search_records`：跳过 `admission_state == Candidate` 的记录（instance 层除外——它不会是 candidate）。
5. hit() 增加 `admission_state` / `classification` / `origin`；`origin` 缺失（v1 行）→ `provenance: "unverifiable"`。
